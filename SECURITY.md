# Security reports

Report vulnerabilities through the repository private vulnerability reporting feature when enabled. Otherwise use The Letterbox linked in README for a private initial report without credentials or private records. Do not publish exploitable details in an issue.

This is a single-owner backend. Isolate databases and credentials for different owners. Keep API keys and backups outside version control. Bind local services to loopback and use TLS for remote access. Security reports are reviewed on a best-effort basis; no response SLA is promised.
